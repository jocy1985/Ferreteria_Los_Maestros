# Ferretería Los Maestros

Proyecto de la asignatura Desarrollo FullStack II — sitio web de catálogo / e-commerce para una ferretería, desarrollado en equipo (3 integrantes).

## Integrantes y responsabilidades

- **Integrante 1** — Inicio, catálogo, estructura general y diseño
- **Integrante 2 Alvaro Araya** — Registro, inicio de sesión, cliente y pedidos
- **Integrante 3** — Carrito, inventario y paneles internos

## Ejecución

Abrir `index.html` en el navegador o utilizar Live Server.
